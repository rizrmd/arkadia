## Interaction states

Built with the built-in imagegen tool from the four original Choosing Hero attachments. Generated masters are preserved; runtime exports use sRGB PNG and straight alpha. The original Choosing Hero page and its four references remain unchanged.

Journey button textures share a 960 × 192 canvas and a blank face. Overlay the English action label as live text. State order: default → hover or keyboard focus → pressed while pointer/key is down → default on release; disabled blocks activation. Generated states have small handcrafted ornament differences, so swap instantly rather than morphing textures. On touch devices use default/pressed; do not require hover.

Selection always combines the glowing frame, check badge and Selected label; color alone is insufficient. Back uses a circular arrow asset; desktop adds the separate Back label. Loadout contains one active skill and two empty slots. Skill name, Empty and Lv. 1 remain separate labels.
