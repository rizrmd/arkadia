## Production layers

Built with the built-in imagegen tool from the four original Choosing Hero attachments. Generated masters are preserved; runtime exports use sRGB PNG and straight alpha. The original Choosing Hero page and its four references remain unchanged.

Desktop and mobile have separately generated castle backgrounds. Both character layers have genuine transparency; keep hair and energy edges with alpha blending. Top-align character canvases before cropping; never stretch faces.
