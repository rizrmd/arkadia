## Ready-to-place exports

Cards are deterministic assemblies of generated hero art, warm or cool backing, transparent frame, selection badge and typography. These are ready-to-place exports. For interactive or accessible UI, use the separate portrait, frame and badge with live English labels from [labels.en.json](/organizations/ORd5dd6f99b4308d6187031557/repositories/RPe11327fbfe413dbeba246526/files?file=public%2Fchoosing-hero%2Fv1%2Flabels.en.json). Portrait exports have a transparent exterior and a dark lower fade; frame exports remain independently reusable.

## Transparent typography exports

These convenience labels use Georgia serif, a system fallback; this is a visual reconstruction, not an extracted proprietary font. Use the crest with the wordmark as shown in the previews. The JSON also includes subtitles, hero descriptions, skill names and help copy for live text rendering.
