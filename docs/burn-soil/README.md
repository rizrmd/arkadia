## Burn Soil — timing and visuals, pending damage balance

Lv.1–2 retain initial damage only. Lv.3–5 create a stationary ground sector at the initial hit, lasting 1000ms, with tick events at +200/+400/+600/+800/+1000ms. The last event runs before expiry. Missed frame deadlines are caught up exactly once. Ground follows existing radius, aim, wall rays and object mask; no projectiles or gameplay range changes.

No approved per-tick damage exists in Flame Fan Knowledge, Ember Ascension Tree, Progression Knowledge, or current TS/Go balance. `BURN_SOIL.damagePerTick = null` and server `burnSoilDamagePerTick = nil` are explicit pending config, not final zero balance. Tick HP mutation is disabled until the human specifies an amount/formula (and whether it differs by rank). Initial damage is unchanged. Server and offline client both run the event lifecycle. No new network authority is assigned to the client.

The main approved shortened preview retains the exact 2/3 hand-relative forward transform, actor positions and existing curls. It adds a ninth inspectable Burn Soil layer, level cycling, five exact tick buttons and English timing/pending-balance labels in Pixi. Preview initial contact is at 220ms, so its tick buttons inspect 420/620/820/1020/1220ms; gameplay keeps its existing 420ms cast release. Relative Burn Soil timing is identical. Older comparison players remain historical baselines.

`node scripts/burn-soil/test.mjs` covers 35 level/cadence cases (30/60/144Hz, coarse/stalled/mixed frames) plus exact boundaries. Go tests cover cadence, level gating, initial damage, five events, expiry and no unapproved HP mutation. `verify-game.mjs` uses a test-only Vite transform on committed encounters to expose controlled step/render and suppress its asynchronous loop; real combat, fighters, masks and GPU visuals run at desktop/mobile. The hook is never shipped. Preview verification exercises actual Pixi pointer controls at 1440×900, 390×844, 844×390 and 320×560, plus cross-origin iframe playback. Browser viewports are not physical-device GPU benchmarks.
