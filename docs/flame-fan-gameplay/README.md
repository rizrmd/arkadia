The live combat renderer uses the shared connected flame material, anchored at the caster's tile and transformed by the actual 64/32 isometric projection and camera. The unit-radius material is bounded by the combat radius and 108° sector. Cast release remains 420 ms; the sheet lasts 850 ms. Rank adds one to five curled strata, heat and modest density. Maximum sheet opacity is 0.385–0.565 instead of the prior preview's 0.675–0.975. There is no bloom or vertical enlargement. Flame Fan contact particles use 0.28 of their previous linear scale. Other skills are unchanged.

The full existing reach is preserved: 4.400 / 5.192 / 5.984 / 6.776 / 7.568 tiles. The existing 0.38-tile target collision allowance, damage, cooldowns and Ember gates are unchanged. Full reach remains broad, especially on a phone; shrinking attack range would change gameplay. The presentation reduction concerns opacity, height, bloom and contact size.

The material is shared by the actual Pixi combat renderer and both NixieFX comparison-player URLs. The sheet uses stationary texture quads, no projectile. It lies under actors, clips against authoritative wall rays, and caches an upright-object silhouette mask per cast through the existing occlusion contract. A 256×256 material updates at 30 Hz with a bounded sprite pool; no animation simulation runs while idle.

Local and public browser reports use actual game casts and real offline damage, with diagnostic stationary enemies to make repeatable checks. All five ranks use five different ground aim directions. Three forward enemies must take damage; rear and out-of-range enemies must remain unharmed. Render telemetry verifies actual radius/rank/aim, zero bloom/height and zero projectiles. Before captures load the original combat module from edaf903 in the same fixture, camera, actor assets and time of day; capture scheduling and random crits can differ. These are browser-emulated desktop/mobile checks, not hardware GPU benchmarks. Online damage remains authoritative on the existing auto-cast tick; no network timing protocol was changed.

## Automatic casting and skill tree

For both heroes, clicking/tapping a HUD skill or pressing 1/2/3 opens the skill tree for that slot. Clicking a learned active node equips it (swapping slots when necessary); these inputs never cast a skill. K opens the tree and Escape closes it. The existing level-up cards still grant learning and rank upgrades, with unchanged 0/4/8-point tier gates and Lv.20 capstone. During a pending card choice, 1/2/3 selects that card as before. Co-op loadout editing retains its existing solo-only restriction.

`automatic-local-1440.json` and `automatic-local-390.json` are the primary gameplay checks. They use actual pointer/touch and keyboard input, controlled eligible level-up offers with the real selection handler, and the real skill-tree equip handler. No manual cast API or forced auto-cast helper is called. Each rank waits for normal gameplay to auto-cast on nearby enemies, then asserts three forward hits, rear/range exclusion, correct visual radius/rank/aim, zero projectiles and no bloom/height. The older `game-before.json` and `game-local.json` captures are isolated sector/visual fixtures, not proof of automatic input behavior.
