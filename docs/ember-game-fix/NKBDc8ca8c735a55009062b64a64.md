## Live game integration — painted Ember Warden

The reported phone screenshot showed the old 3D Ember portrait. The painted redesign had only been published to the art review pages; the game packer still read the legacy v1 animation sources.

The game now packs the painted v2 directional idle/run art and v3 animation atlas into its actual character assets. The picker portrait is regenerated from the painted front idle and has a versioned URL. The atlas has a content revision. Local players and co-op allies use the same updated character manifest.

TypeScript/Vite build, Go tests and deployment smoke checks pass. Browser checks pass locally and on public HTTPS: phone picker, selection persistence, all six walking headings, combat, switching heroes without moving position, and co-op ally updates. No browser errors were recorded. Published atlas, manifest and portrait hashes match the committed files.

### Animation scope

Directional idle/run art covers all six game headings without mirroring. The eight-frame v3 run is used for SE; other headings use the existing four-frame painted run studies. Painted attack, hurt and death exports currently cover SE only and are reused for other combat headings. Combat timing and game rules retain their existing server contract. Directional combat and gait cleanup remain animation limitations.

Requested revision: fire spreads in a fan in front of the character. Default attack: **Flame Fan**, replacing the earlier Ember Bolt proposal. This is a concept sheet for visual review, not a playable animation atlas.

## Identity

A frontier firekeeper with short dark curls, an ochre work jacket, charcoal trousers, leather boots, and a bronze fire gauntlet on the right forearm. Warm amber effects support readability in the snowy Stronghold.

## Default attack: Flame Fan

A short-range cone of fire expands from the gauntlet toward the target. The sheet illustrates approximately 70 degrees as a visual guide; final angle, range, cadence, damage, and burn effects remain balancing decisions. Intended to support attacking while moving.

The sheet includes a portrait, front/side/back turnaround, Ready → Flame Fan → Recover key poses, flame detail, and a top-down footprint.

## Production notes

Validate right-arm gauntlet placement, eight-direction identity, foot contacts, and pose continuity before full animation production. Moving attack animation requires a compact upper-body gesture.

## Generation

Built-in imagegen edit of v01. Prompt: preserve character identity, costume and painterly parchment style; replace projectile attack with a broad continuous forward flame fan; show turnaround, attack key poses and top-down cone footprint; English labels; concept v02.
