## Generated Settings artwork

Generated with the built-in imagegen tool before implementation, using the existing Inventory panel as material/style reference. Original transparent PNGs are retained here; alpha-trimmed, lossless WebP runtime textures are under public/ui/settings/v2. Panel: 768×760. Button: 384×72. Both render as Pixi nine-slice sprites.

Panel prompt: production-ready fantasy RPG panel frame, restrained hand-painted aged brass and charcoal leather, worn bronze bevels, ivory-gold highlights, modest diamond/rivet corners, blank low-contrast center, orthographic square, thin straight edges for nine-slicing, transparent outside, no text/buttons/scene/glow/cyan/modern cards.

Button prompt: one blank horizontal fantasy RPG button matching the panel, raised worn bronze bevel, clipped square corners, fine gold highlights, end rivets, charcoal-brown leather center, straight middle for nine-slicing, transparent outside, no text/icons/glow/cyan/flat UI.

Selected/pressed/focus state and English labels are rendered dynamically by Pixi. No generated lettering is baked into artwork. Original music/speaker/gear artwork is preserved.
